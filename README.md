# Linux-SysAdmin-Portfolio-Project

# A single-server Linux deployment, built by hand — hardened, served, monitored, and backed up.  

This repository documents the complete provisioning of lab-web-01, a Linode VPS running Ubuntu 22.04 LTS. Every step was performed manually, verified, and recorded. There is no Ansible, no Terraform, no shortcuts — just the terminal and the documentation. 

This project covers the several major servers, applications and tool kits which run on Linux, serve, and maintain 80% of global content.
