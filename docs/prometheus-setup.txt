### node_exporter ###

## Step 1: Download and Install the Binary

$ wget https://github.com/prometheus/node_exporter/releases/download/v1.10.2/node_exporter-1.10.2.linux-amd64.tar.gz
$ tar xvfz node_exporter-1.10.2.linux-amd64.tar.gz
$ sudo mv node_exporter-1.10.2.linux-amd64/node_exporter /usr/local/bin/

## Step 2: Create the systemd Service

$ sudo nano /etc/systemd/system/node_exporter.service

[Unit]
Description=Node Exporter
Wants=network-online.target
After=network-online.target

[Service]
User=node_exporter
Group=node_exporter
Type=simple
ExecStart=/usr/local/bin/node_exporter

[Install]
WantedBy=multi-user.target

Now, start and enable it:

$ sudo systemctl daemon-reload
$ sudo systemctl enable --now node_exporter

## Step 4: Verify and Configure Prometheus

$ curl http://localhost:9100/metrics | head



### mysql_exporter ###

## Step 1: Download and Install the Binary

$ wget https://github.com/prometheus/mysqld_exporter/releases/download/v0.17.2/mysqld_exporter-0.17.2.linux-amd64.tar.gz
$ tar xvfz mysqld_exporter-0.17.2.linux-amd64.tar.gz
$ sudo mv mysqld_exporter-0.17.2.linux-amd64/mysqld_exporter /usr/local/bin/

$ sudo nano /etc/.mysqld_exporter.cnf

[client]
user=mysqld_exporter
password=A-Strong-Monitor-Password

## Step 3: Create a Dedicated MySQL User

$ sudo mysql

Then run:

CREATE USER 'mysqld_exporter'@'localhost' IDENTIFIED BY 'A-Strong-Monitor-Password';
GRANT PROCESS, REPLICATION CLIENT, SELECT ON *.* TO 'mysqld_exporter'@'localhost';
FLUSH PRIVILEGES;
EXIT;


Set permissions (the exporter runs as a non-root user, so it needs to read this file):

$ sudo chmod 600 /etc/.mysqld_exporter.cnf
$ sudo chown prometheus:prometheus /etc/.mysqld_exporter.cnf


## Step 4: Create the systemd Service

$ sudo nano /etc/systemd/system/mysqld_exporter.service

[Unit]
Description=Prometheus MySQL Exporter
After=network.target

[Service]
User=prometheus
Group=prometheus
Type=simple
Restart=always
ExecStart=/usr/local/bin/mysqld_exporter \
  --config.my-cnf=/etc/.mysqld_exporter.cnf

[Install]
WantedBy=multi-user.target


Start and enable it:

$ sudo systemctl daemon-reload
$ sudo systemctl enable --now mysqld_exporter


## Step 5: Verify and Check Prometheus

$ curl http://localhost:9104/metrics | head
